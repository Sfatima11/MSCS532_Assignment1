# MSCS532_Assignment1



## Insertion Sort Algorithm in Monotonically Decreasing Order

This project was created for Assignment 1 in the MSCS532 course. The purpose of the assignment is to practice Python programming, GitHub version control, and Visual Studio Code setup by implementing the Insertion Sort algorithm in decreasing order.



## Project Description

The program implements the Insertion Sort algorithm using Python. Unlike the traditional insertion sort that arranges values in ascending order, this implementation sorts the array in monotonically decreasing order.

The algorithm works by:
1. Iterating through the array
2. Comparing elements
3. Shifting smaller elements to the right
4. Inserting the current element into its correct position
